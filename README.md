# משימות – ניהול משימות עם סנכרון ל-Google Calendar

אפליקציית Android (Kotlin + Jetpack Compose) לניהול משימות, מחוברת ליומן גוגל של הטלפון.

## הורדה
כל push ל-`main` בונה APK חתום ומפרסם אותו ב-[Releases](../../releases/latest).

## מה יש
- **Claude בתהליך** – "שפוך את הראש" (טקסט חופשי/קול → משימות מסודרות), סידור התיבה, "תכנן לי את היום" (3 פוקוס + שיבוץ ביומן), "מה עכשיו?", פירוק משימה לצעדים. דורש מפתח API בהגדרות; בלי מפתח יש גרסה מקומית בסיסית.
- **תיבה (Inbox)** – הוספה מהירה עם הבנת עברית ("מחר ב-17 להתקשר לאבא #אישי !"), ומעבר אחד-אחד בשיטת GTD.
- **מצב פוקוס** – טיימר עם צעדים, נספר בסטטיסטיקה.
- **מטריצת אייזנהאואר**, רצף ימים וגרף שבועי.
- **היום** – משימות להיום, משימות באיחור, הוספה מהירה, התקדמות יומית ואירועי יומן גוגל של היום.
- **משימות** – כל המשימות מקובצות (באיחור / היום / מחר / השבוע / בהמשך / ללא תאריך), חיפוש וסינון לפי רשימה.
- **יומן** – רצועת ימים ואג'נדה יומית שמשלבת משימות ואירועים מגוגל.
- **עריכת משימה** – תאריך, שעה, משך, עדיפות, רשימה, חזרה (יומי/שבועי/חודשי), תתי-משימות, תזכורת.

## הסנכרון עם Google Calendar
האפליקציה עובדת מול ספק היומן של אנדרואיד (`CalendarContract`) – כלומר מול חשבון הגוגל שכבר מחובר לטלפון. אין צורך ב-OAuth או במפתחות API.
- משימה עם תאריך → אירוע ביומן (עם שעה = אירוע רגיל, בלי שעה = כל היום), כולל תזכורת.
- סימון כהושלמה → `✓` בכותרת האירוע.
- שינוי שעה/שם/מחיקה ביומן גוגל → מתעדכן חזרה במשימה כשפותחים את האפליקציה.
- אירוע קיים ביומן אפשר להפוך למשימה בלחיצה על ➕.

הנתונים נשמרים מקומית בטלפון (`tasks.json`).
